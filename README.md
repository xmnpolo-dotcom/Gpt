# MIA Android

Aplicación Android nativa basada en WebView que carga la web de MIA en directo.

- URL: https://majestic-baklava-5a712f.netlify.app/
- Las actualizaciones publicadas en Netlify se reflejan al abrir/recargar la app.
- Compilación APK mediante GitHub Actions.

Consulta la pestaña **Actions** y ejecuta **Build MIA APK** para generar el APK de prueba.
